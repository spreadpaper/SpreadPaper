# Security Policy

## Supported versions

Only the latest release on https://github.com/spreadpaper/SpreadPaper/releases gets security fixes. If you run an older version, update first.

## Reporting a vulnerability

Report it privately at https://github.com/spreadpaper/SpreadPaper/security/advisories/new. Do not open a public issue.

Include steps to reproduce, the affected SpreadPaper version, your macOS version, and what the impact is.

You get an acknowledgement within 7 days. Confirmed issues get a fix, or a written answer on why not, within 30 days. You are credited in the release notes unless you prefer not to be.

## Scope

The SpreadPaper app and this repository. The app is sandboxed, runs no background process, and only talks to the network to check GitHub for new releases. Reports about third-party services or the marketing site are out of scope unless the code lives in this repository.
