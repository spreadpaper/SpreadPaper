macOS blocks the first launch

Take either route below. It takes a minute, and only the first time.

Through System Settings

  1. Drag SpreadPaper to your Applications folder.
  2. Open it, then click Done on the warning.
  3. Open System Settings, then Privacy and Security, and scroll to the bottom.
  4. Click Open Anyway, then confirm with Open.

Or in Terminal, before you open it

Drag SpreadPaper to your Applications folder, then run this. It skips the warning entirely.

xattr -dr com.apple.quarantine /Applications/SpreadPaper.app

Gatekeeper, the macOS check that vets apps before they run, asks for a confirmation when an app carries no Apple Developer ID signature.
