The editor

Place the wallpaper exactly where your monitors sit

The canvas is your display arrangement, the one macOS already knows about: the same sizes, the same order, the same gaps. Drop a photograph on it and drag, and it snaps to the middle and to the edges as it passes them, so what you line up here is what lands on the glass.

Zoom, fit and flip

A small set of controls floats over the bottom of the canvas: zoom between 10 and 300 per cent, fit the image to the canvas in one click, and mirror it horizontally when the composition reads better the other way round.

One file for every screen

Each display gets its own rendered file, keyed on the display ID rather than the name, so two identical monitors never end up sharing one picture. Wallpapers go up one at a time, so a second click cannot overtake the first.

Look before you save

Preview puts the wallpaper on your screens with the editor still open, so you can judge it where it will live. Save keeps it as a preset, and Save & Apply does both at once.

Bezel compensation

Monitors have frames, and on a spread wallpaper those frames sit right in the middle of the picture. SpreadPaper pushes the display frames apart by the width of the housing between them, so the photograph carries on behind each frame rather than being drawn on both screens at once. A ridgeline then runs straight across the gap.

That is a trade you are making on purpose: the strip behind each frame is part of the image you never see. Set one width for all your displays or a pair for each of them, horizontal for the left and right edges, vertical for the top and bottom, measured in points. The controls appear once a second display is connected, and Settings holds the gap new displays start from.
